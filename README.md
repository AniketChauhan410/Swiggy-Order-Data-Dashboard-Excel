# 🍔 Swiggy Order Data Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing Swiggy food delivery order data using Microsoft Excel.  
The dashboard provides insights into order trends, customer behavior, revenue analysis, and delivery performance.

---

## 🚀 Key Features
- Order trend analysis
- Revenue and sales insights
- Customer order behavior
- City-wise and category-wise analysis
- Interactive dashboard with slicers
- KPI cards for business insights

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Design
